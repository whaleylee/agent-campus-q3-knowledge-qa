# 题 3 · 企业知识问答 Agent

> 状态：**需求已落盘**（[docs/01-requirements.md](docs/01-requirements.md)），未开始实现。

## 一句话

帮员工找到制度或产品问题的可靠答案——每个结论都有文档原文支持，冲突不擅自裁决。

## 交付结果

回答 · 引用（文档 ID + 原文片段） · 资料缺口 · 任务状态

## 必须验收点（6）

明确答案 · 文档冲突 · 资料外问题 · 改写后的相似问题 · 上下文追问 · 工具失败

## 红线

- 无依据回答、错误引用
- D01（30 天）vs D02（15 天）无优先级时，必须列冲突 + 双引用 + 请求确认，不得擅自回答其一
- 评审会替换文档内容核对答案是否跟着变 → 检索必须真实读 data，答案不得硬编码

## 运行方式（规划）

CLI。实现后在本文档提供可复制的运行命令与评审入口。
