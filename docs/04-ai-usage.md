## 2. AI 辅助范围

以下内容由 AI 辅助生成，本人逐项审阅修改后采用：

1. **初版工具函数**（`src/tools.py` 的检索计分与故障注入骨架）——AI 生成，本人把检索计分从"关键词长度简单求和"调整为现在的版本并补了排序稳定性说明。
2. **ReAct 循环骨架**（`src/agent.py`）——AI 生成，本人核对 JSON 提取的容错逻辑（截取首尾大括号）与工具异常兜底。
3. **测试用例初稿**——AI 生成，本人补齐断言细节（如 case-02 断言 answer 不得含"以新版本为准"）。
4. **文档初稿**——本文档与 docs/02、03 为 AI 起草，事实与数字均取自 `examples/*/output.json` 与 pytest 实际输出，由本人核对。

## 3. 本人修改（AI 初版没有、由本人决策引入的内容）

1. **冲突判定改为归一化文本对比**：AI 初版用正则提取"N 天"数值比较，评审换成"15 个工作日"会漏判（漏判冲突=单边作答=踩一票否决）。改为文本对比是本人基于审核要点的重做，`test_conflict_detection_survives_unit_wording_change` 是为此补的回归测试。
2. **追问定位改数值比对**：AI 初版匹配"哪份/那份"预设问句，属于题面明说不算数的固定分支。改为"问题数值 vs 已读原文"比对。
3. **改写词表外置 data/terms.json**：AI 初版把"打卡→考勤"写死在代码里，换领域即失效。外置 + keywords 反查兜底。
4. **红线取向决策**：引用校验"宁可误拦不可错引"（逐字比对、仅空白归一化），以及冲突不按版本日期裁决——两处都是本人在两种合理设计间做的取舍。

## 4. 验证方式

- `PYTHONUTF8=1 python -m pytest -q`：28 个测试全绿（含上述本人决策对应的回归测试）。
- `PYTHONUTF8=1 python run_examples.py`：7 个用例全部按预期终态结束，产物可一键再生（docs/03 的数字来自 output.json，非手写）。
- 手工核验：随机抽查 trace.md 中引用片段与 data/docs.json 原文逐字一致。
